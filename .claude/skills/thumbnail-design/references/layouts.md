# 썸네일 구도 4가지 (shorts 1080×1920 기준 좌표)

모든 핵심 요소는 안전 영역 x 80~930, y 250~1450 안에 둔다.

## A. 큰 글자 단독 (정보형·팁)
- 메인 문구: box `[80, 560, 850, 560]`, left/top 정렬, max 170
- 위에 강조 막대: rect `[80, 500, 200, 14]`
- 보조 문구: box `[80, 1180, 850, 110]`, plate
- 배경: 단색 또는 2색 그라데이션

## B. 위 사진 / 아래 문구 (제품·요리·결과물)
- background image(사용자 제공) + darken 0.25
- 아래쪽 반투명 판: rect `[0, 900, 1080, 620]` fill #000 opacity 0.55
- 메인 문구: box `[80, 960, 850, 380]`, max 150, 흰색 + 강조색
- 하단 1536px 아래는 UI가 덮으므로 판이 거기까지 가도 문구는 1450 위에서 끝낸다

## C. 대비형 (A vs B, 전/후)
- 화면을 위아래로 나눈 두 rect: `[0, 250, 1080, 600]`, `[0, 850, 1080, 600]` 서로 다른 색
- 각 영역에 문구 1개씩: box `[80, 400, 850, 300]`, `[80, 1000, 850, 300]`, center 정렬
- 가운데 "VS" 원: circle center `[540, 850]`, r 90

## D. 질문형 (궁금증·반전)
