# 숏폼 영상 자동 조립

> **경로:** `{PLUGIN}` = youtube-shorts 플러그인 루트. 이 스킬이 로딩될 때 주어지는 "Base directory for this skill"의 두 단계 위 폴더다(`…/skills/<스킬 이름>` → 상위의 상위). Mac·Linux에서 `python`이 없으면 `python3`.

목표는 **올려도 되는 초안**이다. 컷·확대·자막 수준의 단순한 편집이라, 사용자는 결과를 보고 어색한 부분만 편집 앱에서 손보면 된다. 화려한 전환 효과를 흉내 내지 않는다.

## 준비물 확인

1. 대상 폴더: `output/shorts/{날짜}_{주제}/` (사용자가 지정하지 않으면 가장 최근 폴더). `script.json`이 있어야 한다.
2. 도구: ffmpeg·ffprobe가 없으면 `shorts-setup` 스킬로 설치를 안내한다(영상 조립에는 필수).
3. 화면 소스: `{폴더}/assets/beatNN.png|jpg|mp4` (NN = 장면 번호, 01부터). `script.md`의 제작 체크리스트에 장면별 파일 이름이 적혀 있다.
   - 소스가 하나도 없으면 바로 조립하지 말고 먼저 묻는다: "스크린샷을 넣고 만들까요, 자리 표시 카드로 구성만 먼저 볼까요?"
   - 일부만 있으면 빠진 장면 목록을 보여 주고 진행 여부를 묻는다.
4. 목소리: 프로필(`content/creator_profile.md`)의 "음성 (TTS)" 설정. 없으면 기본 `ko-KR-SunHiNeural`, `+0%`.

## 조립

```
python {PLUGIN}/skills/shorts-video/scripts/assemble_video.py output/shorts/{폴더} --voice {목소리} --rate={+N%} --style output/shorts/{폴더}/thumbnail_spec.json
```
- `--rate`는 반드시 `=`로 붙여 쓴다(`+12%`가 옵션으로 오인되지 않게).
- `--style`을 주면 자리 표시 카드가 썸네일과 같은 배경(그라데이션 또는 AI 배경 이미지)을 쓴다. 썸네일 spec의 배경 이미지 경로는 spec 파일 기준 상대 경로여야 한다.
- 7장면 30초 기준 약 20초 걸린다(장면마다 음성 합성 + 인코딩).

스크립트가 하는 일:
- 장면마다 내레이션을 따로 합성해 **실제 음성 길이로 장면 길이**를 정한다 — 대본의 `t_start/t_end`는 참고만 한다
- 이미지: 흐린 배경 위에 원본 비율 그대로 배치 + 6% 느린 확대 / 영상: 화면을 채우도록 잘라 장면 길이만큼(짧으면 반복)
- 자막(`caption`)은 하단 안전 영역(y 1180~1480)에 반투명 판과 함께
- 소스가 없는 장면: 시리즈 배경 + "장면 N 화면 소스 자리" + 대본의 화면 설명

## 확인과 보고

1. `video_report.json`의 `warnings`를 읽는다: 빠진 소스, 대본보다 2초 이상 긴 영상, 3분 초과.
2. 장면 3~4개 시점의 프레임을 뽑아 눈으로 확인한다:
   ```
   ffmpeg -v error -y -ss {초} -i output/shorts/{폴더}/video.mp4 -frames:v 1 _workspace_shorts/frame_{초}.png
   ```
   Read로 열어 자막 잘림, 소스 위치, 화면 비율을 본다.
3. 사용자에게 보고: 영상 경로, 길이, 장면별 소스(실제/자리 표시), 경고, 다음 행동.
   - 자리 표시가 남았으면 "assets 폴더에 beatNN 파일을 넣고 '영상 다시 만들어'라고 하면 해당 장면이 채워진다"고 안내한다.
   - 영상이 대본보다 길면: 대본 축약(script-writer 재호출) 또는 그대로 사용 중 고르게 한다.

## 주의

- 같은 틀로 대량 생산한 영상은 플랫폼에서 수익화 제외·중복 판정 위험이 있다. 자리 표시 카드가 남은 영상은 **초안**이며 그대로 올리지 말라고 분명히 말한다. 매 회차 직접 찍은 스크린샷과 "맥락 한 줄" 장면이 실제 소스로 채워져야 한다.
- 배경음악은 넣지 않는다(저작권). 필요하면 플랫폼 앱의 라이브러리 음원을 업로드할 때 붙이라고 안내한다.
- 스톡 영상은 사용자가 받은 파일만 쓴다. 인터넷에서 임의로 내려받지 않는다.
