## 분야·목표
- 분야: 개발·IT·AI
- 형식: 정보·꿀팁
- 목표: 구독자 성장 (주 N회 업로드)

## 타깃 시청자
- 20~30대 직장인 (업무 효율, 커리어에 관심). 비개발자도 이해할 수 있는 난이도

## 출연 방식
- 얼굴·목소리 없음 → TTS 내레이션
- 화면 소스: 무료 스톡 영상·이미지 + 자막 애니메이션 + 직접 찍은 스크린샷
- 화면 녹화: 사용 안 함

## 제작 여건
- 빈도: 매일 / 주 2~3회 / 주 1회
- 편집: 최소 편집 (폰 편집 앱) — 반복 가능한 템플릿 포맷 선호

## 말투·톤
- 차분한 존댓말

## 플랫폼
- 유튜브 쇼츠 + 인스타그램 릴스

## 피할 것
- 얼굴 출연, 복잡한 편집이 필요한 포맷
